# Python Network Sniffer
A basic network packet sniffer built with Python and Scapy that captures real-time network traffic, analyzes IP headers, and identifies transport protocols (TCP/UDP/ICMP).

## Prerequisites
* Python 3.x
* Scapy library (`pip install scapy`)
* Npcap driver (for Windows interface routing)
